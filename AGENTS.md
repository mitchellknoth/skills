# Repository work

Run Python development and verification through the tasks in `mise.toml`.
Before submitting code changes, run `mise run eval:check`; refresh generated
skill support with `mise run core:sync` when its canonical files change.

Before writing a README or agent-facing guide, read and apply
[writing-for-agents](https://github.com/mattpocock/skills/blob/5863806dd4e15c63174bee4e7515a4256792ecfa/skills/productivity/writing-for-agents/SKILL.md).

For release preparation or commit-history curation, read
[the release process](.github/knowledge/release-process.md) first.
For benchmark publication, use the [score-history workflow](evals/results/README.md).
