# Preset skill evolution

Read [the shared evaluation and evolution contract](core/skill-evolution.md). Keep the current role-specific methods until comparative evidence supports a replacement or fusion. Candidate recommendations are not observed installation bindings or performance grades.

The public repository includes a pinned candidate assessment under `docs/skill-candidate-assessment.md`. A single-skill installation may not include that repository-level research report; do not invent its conclusions. The source preset still has incomplete full per-bot curated-skill coverage.
